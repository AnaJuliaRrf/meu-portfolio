Destaque IoT · Web · Mobile

NeoVínculo

Monitoramento infantil com IoT

Problema
Acompanhar indicadores como temperatura corporal e oxigenação de crianças exige a integração confiável entre sensores físicos e um sistema de software que centralize e disponibilize esses dados.
Solução
Um ESP32-C3 conectado aos sensores DS18B20 e MAX30102 coleta os dados e os envia para uma API. Um backend processa e armazena as informações, e um aplicativo mobile permite o acompanhamento em tempo real.
Funcionalidades principais
Coleta contínua de dados via sensores, comunicação em tempo real com Socket.IO, API REST para integração entre hardware e sistema, aplicativo mobile para acompanhamento e armazenamento em banco MySQL.
Meu papel
No projeto NeoVínculo, atuei como desenvolvedora responsável pela arquitetura do ecossistema de software de ponta a ponta, liderando a criação do backend RESTful, modelagem e persistência em banco NoSQL orientado a séries temporais, integração do firmware IoT aos servidores em nuvem e consumo de dados em tempo real nas aplicações Web e Mobile.
  • ESP32-C3
  • DS18B20
  • MAX30102
  • Node.js
  • Express
  • MySQL
  • React Native
  • Socket.IO
  • API REST
  • Azure

Fluxo simplificado

Sensores (DS18B20 / MAX30102) → ESP32-C3 → API REST + Socket.IO → MySQL → App mobile (React Native)

Projeto acadêmico

Pede Mais

O Pé de Mais é uma plataforma web desenvolvida para otimizar o fluxo de atendimento, recebimento de pedidos e gestão de estoque de estabelecimentos comerciais. Inspirado no modelo de esteiras de atendimento dinâmicas (como o Anota AI), o sistema centraliza os pedidos em tempo real, permitindo aos operadores acompanhar status (novo, em preparo, pronto, despachado), atualizar disponibilidade de itens no cardápio/estoque e reduzir o tempo de espera no atendimento ao cliente. — projeto acadêmico de desenvolvimento de software.

Ver detalhes
Tecnologias
JavaScript • HTML5 • CSS3
Funcionalidades
Esteira Dinâmica de Pedidos: Acompanhamento visual dos estados do pedido (Novo, Em Preparo, Pronto, Entregue/Finalizado). Gestão de Itens e Cardápio: Interface para visualização, adição e alteração rápida de itens disponíveis. Interface Responsiva e Acessível: Layout estruturado para rápida leitura visual e controle ágil de ações na rotina operacional.
Meu papel
Meu papel foi realizar a construção dos componentes visuais e telas interativas do sistema, priorizando usabilidade (UI/UX), clareza visual para o operador de caixa/cozinha e agilidade nas mudanças de status dos pedidos.
